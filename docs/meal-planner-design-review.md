# Meal planner design review

The implementation is ready for visual review on PR #18. Publication requires Adam's explicit approval. The source revision used for browser captures is `296888e28cac077c8fb2f74565985e9b907be47b`.

[Working review with selectable widths](https://raw.githack.com/adam01smith-ai/Cookbook/296888e28cac077c8fb2f74565985e9b907be47b/docs/previews/meal-planner-review.html?width=1440)

The preview service can show an external-content notice on first use. Its browser storage is separate from adamcooks.co.uk. The screenshots show a week generated by the real planner for testing. They do not represent Adam's personal meal plans. Dates, recipes and scores are calculated from the current planner state.

## Implementation

The homepage wordmark, mobile navigation, green palette and serif headings are reused. Settings sit in one panel, followed by a real date range, preview action and calculated variety report. All seven days appear as photographic cards. Each card has Keep, Swap, View recipe and an expandable editor containing the existing day type, recipe, sides, extra portions, feedback and swap preferences.

The support panel uses Adam's supplied original JPEG with CSS cropping. His face and features have not been regenerated. The background remains the stadium in the original photograph. The button opens the existing planner section of the how-to-use guide.

Shopping and History retain their existing controls, aggregation and confirmation behaviour. Core scoring, the multi-candidate generator, weights, storage keys and consent code are byte-for-byte identical to main. The current model has one active draft and confirmed history. Week selection still restores confirmed weeks and warns before replacing an unconfirmed draft. Independent future-week drafts remain a separate enhancement.

The existing traybake sharing JPEG is 1200 × 630 while its metadata claimed 1200 × 800. The dimensions in its social tag are corrected so the existing release test passes. Its photograph and recipe content are preserved.

## Differences from the illustrative mockup

- The hero uses the repository's Jack Daniel's Glazed Chicken photograph.
- All seven calendar days are included, so the page is longer.
- Real recipe titles, times and planning descriptors replace the illustrative labels. Nutrition claims are not added.
- Editing and portion controls expand within each card.
- The original stadium portrait is cropped beside the support text on desktop, then stacks below it on a narrow screen.
- Existing saving notices, privacy controls and device backup guidance remain visible when applicable.
